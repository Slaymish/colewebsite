Features that cross pages

Features

  • Featured work wheel. A carousel of slides on an arc, one focused at a time, with "See all" underneath going to the work cloud. Renders only when there are enough featured pieces to be a wheel; below that the page links straight to the cloud and the block does not exist. The threshold is a single constant,WIREFRAME.featuredMinimum in src/lib/wireframe-content.ts.
  • Silly cookies disclaimer. One line, in voice, with a dismiss. Shown closed on every page; no handler yet — the static build's CSP refuses inline script, so dismissal needs a bundled script and a stored preference.
What the strip changed

  • Infrastructure, the content model, the CMS boundary, SEO and the deploy pipeline → untouched
